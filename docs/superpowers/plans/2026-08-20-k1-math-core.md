### Task 1.2 `src/lib/math/tex.ts`

Implement per Spec §2.3:

```ts
export function htmlUnescape(s: string): string; // &lt; &gt; &amp; &quot; &#39; etc.
export function attrEscape(s: string): string;
export function protectAndRenderMath(
  escapedWithCodePlaceholders: string,
  put: (html: string) => string,
): string;
```

Rules:
- Match `$$…$$` first (multiline), then `$…$` same-line only
- Optional: `\(`/`\)`/`\[`/`\]` OK but not required for green tests
- Skip existing `\uE000n\uE001` placeholders
- `htmlUnescape` extracted tex before `katex.renderToString`
- `throwOnError: true`, try/catch → `<code class="soit-math-fallback">`
- display: put div, ensure **own lines** around PH for PH_ONLY consumers
- inline: put span with data-tex attr-escaped
- Never second PH alphabet
