## UX

- **Not** full 360° mandala in 200px — **side arc** on the right side of the rail column (labels readable).
- Center: button with root title (truncated), aria-label 根探究.
- Ring 1: vertical curved list (Option Wheel feel: active larger, neighbors faded/blurred); support wheel scroll to move selection + click.
- Ring 2: smaller, more faded, offset; only if `rings[2].length`.
- Kind: deepen vs diverge visual (color tick or prefix ↓/↗).
- Unread: small dot.
- `prefers-reduced-motion`: flat stacked buttons, no blur animation.
- Props:

```ts
type Props = {
  model: OrbitModel; // from orbitLayout
  onSelect: (id: string) => void;
  className?: string;
};
```

## Inspiration (do not vendor whole GSAP libs)

- React Bits Option Wheel: curve, fade, blur by distance from active, smoothing, side left/right.
- Implement with CSS + rAF or simple state index; **no new npm dependency** unless already in package.json.
