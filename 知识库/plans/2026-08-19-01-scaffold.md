### Task 1: 初始化前端与 Tauri

**Files:**
- Create: `package.json`, `package-lock.json`, `vite.config.ts`, `tsconfig.json`, `tsconfig.node.json`, `index.html`, `src/main.tsx`, `src/App.tsx`, `src/vite-env.d.ts`, `src-tauri/**` (via create-tauri-app or manual)

**Interfaces:**
- Produces: runnable `npm run tauri dev`

- [ ] **Step 1: 检查工具链**

```bash
node -v
npm -v
rustc -V
cargo -V
```

Expected: Node LTS, rustc stable. 若缺 WebView2/Rust，写入 README 阻塞说明并尽量安装。

- [ ] **Step 2: 用官方方式生成或手写脚手架**

优先（在仓库根）：

```bash
npm create vite@latest . -- --template react-ts
```

若目录非空导致失败：手动创建 `package.json` + Vite React-TS 文件，不要删除 `知识库/`。

然后：

```bash
npm install
npm install -D @tauri-apps/cli@2
npm install @tauri-apps/api@2
npx tauri init --app-name Soit --window-title Soit --dev-url http://localhost:5173 --before-dev-command "npm run dev" --before-build-command "npm run build" --frontend-dist ../dist
```

（`tauri init` 参数以 CLI 实际提示为准；保证 `tauri.conf.json` 里 productName/title 为 Soit，identifier 为 `lab.soit.app`。）

- [ ] **Step 3: 最小 App**

`src/App.tsx` 仅渲染：

```tsx
export default function App() {
  return (
    <div style={{ fontFamily: "system-ui", padding: 24 }}>
      <h1>Soit</h1>
      <p>scaffold ok</p>
    </div>
  );
}
```

`index.html` 不要引入 Google Fonts。

- [ ] **Step 4: 验证**

```bash
npm run build
```

Expected: `dist/` 生成成功。

```bash
npm run tauri dev
```

Expected: 窗口标题含 Soit，可见 “scaffold ok”。若失败，记录完整错误到 README「环境」节。
