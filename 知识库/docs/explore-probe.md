## 1. 主工作区骨架（桌面）

四块 + 壳，实测与早前截图笔记一致，细节补全如下。

```
┌──────────┬──────────────────────────────┬─────────┐
│ 左栏     │  中：单张大卡（四周留空）      │ 右：节点 │
│ 项目/动作│                              │ 图导航  │
│          │  ┌────────────────────────┐  │         │
│          │  │ 标题 + 卡头三钮         │  │  ○─●─○ │
│          │  │ 消息流 / 折叠轮次       │  │    │    │
│          │  │ 底部水印（淡）          │  │         │
│          │  └────────────────────────┘  │         │
│          │   ○ 分支   ○ 子卡   ○ 发散    │         │
│ 设置/账户│  ════════════════════════    │         │
│          │  作曲条（卡外）：模型|上下文|输入|附件|发送 │
└──────────┴──────────────────────────────┴─────────┘
```

| 区 | 实现要点 |
|----|----------|
| **左** | 顶：切换侧边栏 / 新建文件夹 / 新建项目 / 文档阅读 / 导入项目。中：常驻对话、本机项目（可拖拽排序）、云端项目（会员）。底：设置、账户。整栏可关。 |
| **中** | **一张**圆角大卡（约 `rounded-[24px]`），不贴边；标题「应用介绍」；卡头右上三圆钮；消息可折叠（「点击该轮对话以展开」）；卡内底部淡水印。 |
| **右** | SVG **节点图**（非文字树）：`tree-node-current` 实心较大，`tree-node-default` 空心；边上可有 brand 色未读小点；容器 `cursor-grab` + 边缘 fade mask。 |
| **底（卡外）** | 作曲条：模型选择、上下文占用环（`上下文已用 0%`）、多行输入、附件/发送类圆钮。Placeholder：`探索一切...... (Enter = 换行) \| (Ctrl+Enter = 发送)`。 |
| **卡下沿** | 三个粉圆钮，创建下游卡（见 §3）。在卡外、作曲条之上。 |

视觉（Sakura 主题样本）：壳底 `#e4f0fa` 一类冷浅色；卡白/米 + 粉描边 `rgb(232,200,220)`；阴影偏软 `rgba(0,0,0,.3) -4px 8px 24px`；控件大量圆角胶囊。Soit 共识已写 **不借粉彩玩具风**。

## 2. 信息架构 / 功能地图

### 2.1 项目与存储

| 能力 | 说明 |
|------|------|
| 项目 | 一项目一卡片树；左栏列表；教程项目「应用介绍」预装 |
| 本机 / 云端 | 左栏分区；云端标「会员专属」 |
| 文件夹 | 可新建文件夹归类项目 |
| 导入项目 / 文档阅读 | 左栏入口；文档导入后同样走层级对话；AI 分块、翻译、排版（产品文案） |
| 同步冲突 | 对话框：加载远端 / 复制为新项目 / 强制覆盖云端 |
| 布局 | 竖屏可提示切手机布局；设置里有界面缩放（默认 90%，50–200%） |

### 2.2 卡片与层级对话（核心）

产品自己定义 **三种** 长卡（与 Soit v1 的「深挖+发散」不同，多了 **分支**）：

| 符号 | 名 | 上下文继承（产品文案） | 桌面按钮方位 |
|------|----|------------------------|--------------|
| ↗ | **子卡片** | 读上游「对应标题」作背景主题 | 主卡 **上方**；卡下沿 **中** 钮（上下分栏 +） |
| → | **发散卡片** | 读上游标题作关联主题 | 主卡 **右**；卡下沿 **右** 钮（左右分栏 +） |
| ↓ | **分支卡片** | 继承主题 + **分支点前对话记录** | 主卡 **左**；卡下沿 **左** 钮（hexagon） |

补充：

- 下游卡自动读上游相关信息（作用域式，不是整棵树裸灌）。
- 右栏节点点击切换当前卡；未读点可右键手动切换（文案）。
- 卡头工具（从左到右图标）：**复制/另开类**、**收藏（书签）**、**删除（垃圾桶）**。
- 对话轮次可折叠；有「思考完成 Xs」折叠条。
- 用户气泡靠右；助手在卡内正文流。

### 2.3 智能标注（下划线）

| 点 | 实测 |
|----|------|
| DOM | `span.conceptual-term.ct-armable` |
| 表现 | 文内下划线术语；示例「Explore」「Explore的智能标注功能」；公式也可点（文案） |
| 点击 | 弹出 **浮动小卡** `bg-card-floating`（非立刻换主卡） |
| 浮卡工具 | 三个与长卡同构的方向钮 + 关闭；未登录时正文为「请先登录后再使用内置模型。」 |
| 文案路径 | 预览解释 → 仍不懂则点 **子卡片** 继续下钻 |

Soit 对齐点：共识是「点下划线 → **先选深挖/发散** → 建卡」。Explore 是「点术语 → 浮层解释 → 浮层上再长卡」。Soit **不必**抄浮层解释，但「先选方向再进卡」与 Explore 浮层上的三向钮是同一类手势问题。

### 2.4 上下文与消息操作

| 能力 | 来源 |
|------|------|
| 选中 AI 文本引用（可多处） | 产品文案 |
| 悬浮栏重新生成 | 产品文案 |
| 对话导航栏删一轮 | 产品文案 |
| 右键改自己的消息 | 产品文案 |
| 设置「可修改 AI 回复」 | 非流式回复可右键编辑（设置页文案） |
| 作曲条上下文环 | `aria-label="上下文已用 0%"`，可展开 dialog |

### 2.5 收藏 / 总结 / 思维宇宙

| 能力 | 说明 |
|------|------|
| 收藏对话 / 项目 | 卡头书签；项目批量收藏 |
| 收藏区 | 列表看对话；卡片视图看「≥2 轮收藏」的项目；可导出 |
| 项目总结 | 收藏项目上可智能总结，把探索串起来 |
| 思维宇宙 | 用户用自己的话写理解 → AI 校验 → 写入宇宙；之后讲解作「思维锚点」。免费上限约 30 节点（定价文案） |

Soit：**思维宇宙 / 第二套笔记** 已在非目标；真实内存走 Obsidian。收藏+总结的「沉淀」动机可参考，落点不同。

### 2.6 设置面板（弹层，约 75% 视口）

左导航 + 右内容；底 **恢复并关闭** / **保存**。

| 页 | 内容（探查到的） |
|----|------------------|
| 可用模型 | 内置列表；档位 Free/Plus/Pro/Max；倍率；供应商；「添加 BYOK 模型」（免费 1 个） |
| 模型分配 | **对话性模型**（直接对话，可多选/添加）；**功能性模型**（标题、智能标注、项目总结）；**视觉模型**（视觉→文本，供非视觉对话模型） |
| 自带密钥 | 统一 BYOK：供应商 API Key、OpenAI 兼容端点、ChatGPT 账号（浏览器授权 / 设备码） |
| 颜色主题 | Default / Warm / Midnight Forest / Sakura / Memphis / Sunset / 暗紫/蓝/橙… |
| 修改权限 | 「可修改 AI 回复」等开关（部分文案） |
| 快捷键 | 有独立页（本次未逐项抄表） |
| 自动行为 | 有独立页（本次未逐项抄表） |
| 语言 | AI 默认遵循 UI 语言；可用任意自然语言描述「语言风格」 |
| 布局 | 界面缩放 slider 默认 90% |

### 2.7 账户 / 商业

个人中心页签：个人信息、额度、账单、个人背景、收藏、思维宇宙。  
方案：Free / 试用 $1 / Go $3 / Plus $5 / Pro $9 / Max $20；微信/支付宝；Beta 席位满可留资。  
Soit：本机 BYOK，不做这套云订阅身份。

## 3. 面板组件清单（给 Soit UI）

### 3.1 建议对标实现的结构

1. **左：宇宙/项目管理**（Soit：vault/宇宙列表，不是「本机/云端」产品身份）
2. **中：单探究卡**（大、留白、圆角、阴影分层；工具长在卡上）
3. **右：空间节点图**（点+曲线；当前实心；未读点可选）
4. **卡外作曲条**（模型 BYOK、上下文用量、输入；Enter 策略可自定）
5. **卡缘长卡手势**（Soit 仅深挖+发散；**不要**做 Explore 的第三种「分支=带 transcript 分叉」除非共识改）

### 3.2 交互细节（已证实或强文案）

| 交互 | Explore | Soit 建议 |
|------|---------|-----------|
| 主手势 | 对话 → 下划线 → 浮层/长卡 | 对话 → 下划线 → **先选深挖/发散** → 进卡 |
| 长卡种类 | 子 / 发散 / 分支 | 深挖 ≈ 子；发散 ≈ 发散；**分支不建树**（重来在卡内） |
| 树导航 | 右栏图，点切换 | 借 |
| 未读 | 节点小点，可右键 | 可后置 |
| 卡头 | 复制类 / 收藏 / 删 | 按 v1 需要裁（收藏若=沉淀到 Obsidian 要另设计） |
| 消息折叠 | 旧轮折叠 | 可借 |
| 长按按钮说明 | 文案明确 | 可借（桌面可用 tooltip） |
| 多主题皮肤 | 强 | v1 一套成品即可 |
| 登录墙 | 强 | Soit 本机无此墙 |

### 3.3 DOM / 实现线索（逆向参考，非规范）

- 卡：`.card-container` / `.bg-card-std` / `shadow-card` / `rounded-[24px]`
- 标注：`.conceptual-term.ct-armable`
- 树：`.mask-tree-edge-fade`，`circle.tree-node-current|default`
- 作曲：`.bg-inputarea` 大圆角条
- 浮层：`.bg-card-floating`、设置 `.bg-modal-std` + `.bg-overlay-modal`
- 技术味：Inter、Lucide、Tailwind 工具类、偏 React SPA

## 4. 与 Soit 共识对照

| Explore | Soit 已拍板 |
|---------|-------------|
| 云端账号 + 订阅 + 本机/云项目 | 本机独立进程；一 vault 一宇宙 |
| 卡片树是产品中心 | 同：卡片=探究虚拟文件 |
| 三种长卡（含子/发散/分支） | 仅深挖+发散；重来不建卡 |
| 智能标注浮层解释 | 可点概念；方向选择后进卡；记忆不进浮层而进 Obsidian |
| 思维宇宙 | 非目标；Obsidian 为真实内存 |
| 文档阅读工作区 | v1 未承诺；可后置 |
| 模型三角色（对话/功能/视觉） | 可借鉴分配思路；BYOK |
| 粉彩多主题 | 不借玩具风；成品观感另定 |
