## 1. 身份

Soit 是本机 **Agent Host**。

第一性工作是 **会话操作系统**：让自我驱动的学习者能管理、整理、恢复、分叉会话。不是课程平台，不是测验机，不是目标锁。

用户对着内置 Agent 聊。卡片树是它的原生工作区（替代线性聊天栏和文件树）。Skills 跑在 Soit 里。支持 **BYOK**。

Obsidian 是官方记忆后端，不是第二个聊天框，也不是宿主。

## 2. 两层记忆

| 层 | 是什么 | 不是什么 |
|----|--------|----------|
| 卡片 | 虚拟文件。一次 **探究**（inquiry） | 不是概念闪卡，不是一篇笔记的镜像 |
| Obsidian | 真实内存。给人复访、检索、改写 | 不是会话存档，不是聊天导出目录 |

一张卡片同时有：

- **对话路径**：Agent 当前看见的工作记忆
- **探究状态**：在问什么、卡在哪、下一步、活/停

从对话里长出下一张卡片是主手势，不是附加功能。正常学习就是：和 AI 对话 → 某个概念不会 → 点下划线 → 短解释（可选）→ 选方向 → 进新卡片继续。新卡片仍是一张探究，不是一张词条。

## 3. 分叉

v1 只承认两种长卡方式：

| 方式 | 关系 | 上下文 |
|------|------|--------|
| **深挖** | 垂直。同一条探究往下 | 只带作用域：父卡状态 + 点中的原文 +「为什么跳下来」。需要时 Agent 再读父卡 |
| **发散** | 平行。同一层另一条 | 空白对话 + 一条指回源卡的边 |

规则：

- **重来不是新卡片。** 换一种讲法、再生成，都在同一张卡内部完成。旧回合可留在该卡历史里，树不为此分叉。
- **父卡不因发散而自动停住。** 两边都还活着。树是关系，不是一串强制暂停。
- **两边都能长卡**：用户和 Agent。
- **单击带下划线的文字（通常是概念）可先短解释（不建卡）；建卡前须先选深挖或发散，再进入新卡。** 不是静默深挖。

不在 v1 做：合并两条探究、把重来做成第三种卡片类型。

## 4. 写入 Obsidian

Agent 有写记忆的工具；用户也可以随时触发沉淀。

写出规则：

- 带指回源卡片的引用
- 不把整段 transcript 倒进库
- 用户在 Obsidian 里改过的正文，默认不覆盖

落库原子（不是一卡一笔记）：

| 原子 | 落点 | 何时 |
|------|------|------|
| 稳定下来的概念 | `concepts/` | 结论已经站得住 |
| 跨天还要用的残渣 | inquiry / log | 未决问题、下一步、卡住点、指回哪张卡 |

卡片本身只活在 Soit 宇宙里。

## 5. 宇宙与进程

- Soit 是 **本机独立进程**，不是 Obsidian 插件，不是云端产品，不挂在其他 Agent Host 上。
- 在 App 里选定一个 Obsidian vault。
- **一个 vault = 一个卡片宇宙**，彼此隔离。
- 宇宙物理位置：`vault/.soit/universe.db`。跟着 vault 走。拷贝 vault = 拷贝宇宙。
- `.soit/` 不是知识库。Wiki 仍是给人看的 Markdown。Obsidian 把 `.soit` 当普通应忽略目录。
- 壳：**Tauri + Web 前端**。界面按成品做。

## 6. 技能

v1 技能 = 可修改的 **SKILL.md**。

- 内置先做两件事：**整理卡片宇宙**、**整理 Obsidian 库**
- Agent 能启用 / 停用 / 改写
- 人也可以改文件，改完即生效
- v1 无代码插件、无插件市场
- 目录结构预留以后接代码插件的门，v1 不实现

## 6.1 Agent 双轨

Soit 是 **会话 Host**：卡片宇宙与探究语法的权威在 Soit，不在外部 agent session。

| 轨 | 角色 | 说明 |
|----|------|------|
| **主轨 Inquiry Assistant** | 卡内探究对话 | 一卡一上下文；BYOK 或 Mock；深挖 / 发散 / 重生规则不变 |
| **副轨 External Runtime** | 可选执行后端 | 本机 coding agent（CLI/ACP 等）作 **工具级 handoff**；导出 brief → 运行 → 结果写回 turn/残渣；**不拥有**卡片树 |

禁止：

- 把外部 session 目录当作卡片源或宇宙权威
- 以「Soit 作为其他 Host 的插件」为默认路径
- v1 子 Agent 舰队 UI

实现细节见 `docs/superpowers/specs/2026-08-20-agent-dual-track-spec.md`（v1.1）。

## 7. v1 闭环（成品，不是原型）

必须同时成立：

- 卡片功能完整（树 / 堆叠导航算主循环，要做好）
- 对话功能完整
- Obsidian 整理体系能用、能成熟运转
- BYOK
- 前端观感按可天天用的产品做，对标 Explore、DSH 的完成度

明确后置：

- 技能编辑 GUI / 市场
- MindScape 级「思维宇宙」
- 第二套笔记编辑器
- 子 Agent 舰队

## 8. 默认（未单独拍板，按此做；要否现在改）

- v1 **单探究助手 + 可选外部 Runtime**（工具级 handoff，非多 Agent 舰队）
- 前端 **React**
- 回复里由 Agent 标出可点概念；用户也可以选中任意文本再分叉
