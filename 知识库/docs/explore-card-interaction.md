## 1. 卡片分层（由外到内）

```
舞台（四周留白）
└─ 卡片壳 .bg-card-std  rounded-[24px]  shadow-card
   ├─ 顶栏：标题「应用介绍」 + 卡级三钮（常显）
   ├─ 右缘：对话轮次导航轨（默认极窄 ~20px，可展宽）
   ├─ 主滚动区
   │   ├─ 折叠轮次条（「点击该轮对话以展开」+ 标题）
   │   ├─ 当前轮：用户气泡 / 思考条 / 助手正文
   │   ├─ 智能标注 span.conceptual-term
   │   └─ ai-selection-root（划词命中层）
   ├─ 滚动提示：左上 ↑ / 右下 ↓（默认 opacity:0，与滚动相关时出现）
   └─ 卡外下沿三钮（常显，贴卡底外侧）
作曲条（再下一层，完全在卡外）
```

关键 CSS 线索：

| 区域 | class / 特征 |
|------|----------------|
| 卡壳 | `.bg-card-std` `rounded-[24px]` `shadow-card` |
| 轮次功能条 | `.bg-bar.shadow-floating-functionbar` 横向胶囊 |
| 正文复制条 | `.bg-bar.shadow-floating-copybar` 纵向 |
| 划词条 | `absolute z-30 flex flex-col gap-1`（非 bg-bar 命名） |
| 标注 | `.conceptual-term.ct-armable` → hover 加 `.ct-armed` |
| 标注浮卡 | `.bg-card-floating` |
| 提示气泡 | `fixed z-[130] ... bg-modal-floating` |
| 轮次右轨 | `absolute right-0 z-15 ... transition-[width]` |
| 滚动钮 | `absolute z-30 ... bg-btn-floating` chevron |

## 2. 卡级控件（标题行，常显）

位置：卡内右上，粉圆钮。

| 顺序 | 图标 | 悬浮文案（实测） |
|------|------|------------------|
| 1 | 卡片+加号 | **从此卡片创建新卡片**（子卡 / ↗） |
| 2 | 书签 | **收藏卡片** |
| 3 | 垃圾桶 | **删除此卡片及其子卡片** |

说明：子卡创建挂在**卡头**，不在卡下沿三钮里（与产品文案「子卡在主卡上方」一致）。

---

## 3. 卡外下沿三钮（常显）

贴在大卡底边外侧，不进作曲条。

| 位置 | 图标 | 悬浮文案（实测） |
|------|------|------------------|
| 左 | hexagon | **思维宇宙** |
| 中 | 上下分栏 + | **从此卡片创建分支卡片**（↓） |
| 右 | 左右分栏 + | **从此卡片创建发散卡片**（→） |

注意：中钮是 **分支**，不是子卡。子卡 = 卡头第一钮。

## 4. 对话轮次（Turn）悬浮功能条

**触发：** 鼠标进入某一轮助手内容区域（含折叠条附近）后出现。  
**形态：** 横向胶囊 `shadow-floating-functionbar`，贴在该轮上方/右上。  
**作用域文案都是「从此对话…」**（turn 级，不是整张卡）。

| 顺序 | 图标 | 悬浮文案 |
|------|------|----------|
| 1 | 卡片+ | **从此对话创建新卡片** |
| 2 | 左右分栏+ | **从此对话创建发散卡片** |
| 3 | 上下分栏+ | **从此对话创建分支卡片** |
| 4 | 书签 | **收藏对话** |
| 5 | 刷新 | **重新生成** |
| 6 | 垃圾桶 | **删除** |

与卡头对照：

| | 卡级 | 轮次级 |
|--|------|--------|
| 长出子/散/支 | 仅子卡在头；散/支在卡底 | 三向都在轮次条 |
| 收藏 | 收藏**卡片** | 收藏**对话** |
| 删除 | 删卡及子树 | 删本轮 |
| 重生成 | — | 有 |

## 5. 助手正文旁：复制条

**触发：** 悬停助手消息块。  
**形态：** 纵向小条 `shadow-floating-copybar`，靠正文左侧或选区附近。

| 顺序 | 图标 | 悬浮文案 |
|------|------|----------|
| 1 | copy | **复制文本** |
| 2 | check / md | **复制 Markdown** |

（界面里第二枚常画成 `</>` 风格，语义是 Markdown 复制。）

## 6. 用户气泡

**触发：** 悬停右侧 `Hi!` 类用户气泡。  
**表现：** 气泡旁出现小型 **复制** 图标（路径同 copy）。

文案称可 **右键修改自己的消息**（本次未测右键菜单全文）。

## 7. 智能标注（下划线术语）

| 状态 | 表现 |
|------|------|
| 默认 | `conceptual-term ct-armable`，下划线 |
| Hover | 加 class `ct-armed`，背景高亮（Sakura 下约 `rgb(255,208,229)`），下划线可消 |
| 单击 | 弹出 **浮动解释卡** `.bg-card-floating`（不替换主卡） |

浮卡顶栏三钮 + 关闭（文案与轮次长卡同构，作用域写「对话」）：

| 钮 | 文案 |
|----|------|
| 子 | 从此对话创建新卡片 |
| 散 | 从此对话创建发散卡片 |
| 支 | 从此对话创建分支卡片 |
| × | 关闭 |

访客态正文：「请先登录后再使用内置模型。」——解释内容需登录，**交互壳完整**。

## 8. 划词（选区）工具条

**触发：** 在助手正文中拖选文本（存在 `.ai-selection-root` 命中层）。  
**形态：** 选区旁纵向三钮 `z-30 flex flex-col gap-1`。

| 图标 | 悬浮文案 |
|------|----------|
| zoom-in | **从选中文本创建预览**（≈点标注出浮层，不立刻长主卡） |
| message-square-quote | **引用选中文本** |
| copy | **复制** |

与产品文案「提问 / 引用 / 复制」对应关系：预览 ≈ 快速弄懂选区；引用进输入上下文；复制进剪贴板。

## 9. 轮次导航（卡内右缘）

| 项 | 实测 |
|----|------|
| 默认 | 右侧一条窄轨 ~20px 宽，`z-15`，`items-end` |
| 内容 | 「点击该轮对话以展开」+ 各轮标题（如「应用设置介绍…」「应用功能介绍…」） |
| 展开 | `transition-[width]`，可扩到 ~200px+ 显示完整标题 |
| 交互 | 点标题切换/展开该轮（折叠态文案明确） |

与**整棵树的右栏节点图**是两套东西：节点图在工作区最右；轮次轨在**当前卡内部**右缘。

## 11. 提示（Tooltip）系统

- 几乎所有图标钮：**悬停约 ≥0.5–1s** 后出 `fixed z-[130] bg-modal-floating` 小标签。
- 产品文案写 **长按** 也可出说明；桌面以 hover 为主。
- 合成 `mouseenter` **不可靠**；必须 CDP 真实 hover，并等待 2–3 秒。

## 12. 给 Soit 的结构建议（仅交互层）

### 建议借

1. **两级动作域分清**  
   - 卡级：删卡、收藏卡、从卡长子探究  
   - 轮次级：重生、删轮、从**这一轮**长深挖/发散  
2. **助手消息 hover → 横向功能条**（深挖 / 发散 / 收藏轮 / 重生 / 删）  
3. **划词 → 预览 | 引用 | 复制**（Soit：预览可做成「先选深挖/发散」的入口，不必抄三向分支）  
4. **标注：hover 高亮 → 点击浮层 → 浮层上再选方向**（或 Soit 共识：点击后直接二选一不先解释）  
5. **卡内轮次轨**（多轮时）与 **工作区右栏节点图** 分离  
6. **输入永远在卡外**；长卡钮可卡缘，不进输入条  

### 建议改 / 不借

| Explore | Soit |
|---------|------|
| 三向：子 / 散 / 支 | 仅 **深挖 + 发散**；重来 = 轮次「重新生成」，不建树 |
| 卡底「思维宇宙」 | 非目标 |
| 粉彩悬浮条 | 可保留「胶囊功能条」形态，换成品视觉 |
| 分支=继承 transcript | 不做；上下文规则见对象模型 |

### 建议默认信息架构（草案）

```
卡头：标题 | 深挖(子) | 沉淀/收藏 | 更多(删…)
轮次条(hover)：深挖 | 发散 | 重生 | 删轮 | …
划词条：预览或方向选择 | 引用 | 复制
标注：高亮 → 方向选择 → 新卡
卡缘外：可选深挖/发散快捷（若与轮次条重复可只留一处）
卡外底：作曲条（模型 · 上下文 · 输入）
```

## 14. 探查方法备注

1. 设置弹层会挡住 hover：需关闭或临时移出 DOM（勿 `display:none` 主壳）。  
2. 每步 **CDP hover → wait 2.5–3s → 读 `.bg-modal-floating` 文案 / 截图**。  
3. 功能条可用脚本强制 `opacity:1` 便于连读 tooltip，但首次发现仍应靠真实悬停。
