# 非目标

写下来是为了防止实现时把产品做成别的东西。

## v1 不做

- 课程、课表、强制测验、目标锁、学习路径生成器
- 把重来做成树上的第三种卡片
- 合并两条探究
- 一卡一笔记、持续把聊天镜像进 Obsidian
- 发散时自动停住父卡
- Soit 做成 Obsidian 插件
- Soit 做成云端多租户
- 挂在 DSH / Pi / 其他 host 上当插件
- 代码插件系统、插件市场、技能 GUI 编辑器
- MindScape / 思维宇宙级空间
- 第二套笔记编辑器（Obsidian 已经是真实内存的编辑面）
- 子 Agent 舰队
- 医疗 / 法律 / 代写作业产品定位（学习辅助，结论需人核）

## 失败路径（不要走回去）

曾用 DSH 插件 + 侧栏卡片 + 把流程写进 host 的方式做过一版，已判定失败。从中只吸收反面：

- 不要把会话结构寄存在别人的 session 模型上
- 不要还没做稳树，就叠流程、测验、研究仪式
- 不要让「整理」变成只有人喊「沉淀」才发生的额外作业
- 不要把卡片做成 host 的皮肤

## 不要和谁正面撞

- 不要做 Explore 的 UI 克隆（他们已经赢了「对话变卡片」）。Soit 的差别是：卡片是探究状态，vault 是真实内存，Soit 自己是 Agent Host。
- 不要做另一套 PKM。Obsidian 已经是库。
- 不要做 SRS / 闪卡工厂。
- 不要做「把一句话生成一门课」的产品。
