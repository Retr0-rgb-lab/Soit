# 活线 / 停养 = 注意力集合

> Spec：`2026-08-20-philosophy-alignment-spec.md` §7 命名围栏 · Wave F

## 定义

| 词 | 含义 | 不是 |
|----|------|------|
| **活线** | 用户当前愿意放在注意力里的探究根（左栏钉住，上限见 `LIVE_MAX`） | 探究的业务 status、打开/关闭状态 |
| **停养** | 把某根从活线集合里移出 | 「停掉父探究」、归档、删除、改 card status |
| **钉入活线** | 把某根加入注意力集合 | 收藏、沉淀、写入 Obsidian |

## 不变量

1. 活线只影响**导航与提醒**（左栏列表、再进入条等），不改卡片树、边、或 `universe.db` 里的探究语义。
2. 焦点自动 pin 根 = 进入注意力集合，**不等于**把卡片标为「进行中」。
3. 停养后卡片仍在库中、仍可从最近 / 图谱 / Ctrl+K 打开；只是不再占用活线名额。
4. 线债（未读按 root 聚合）与活线正交：未读可发生在非活线上。

## UI 文案

- 停养 tooltip 应暗示「移出活线 / 注意力」，避免「停止探究」。
- 禁止把活线做成第二套「记忆库」或「收藏夹」叙事。
