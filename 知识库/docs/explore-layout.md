# Explore 布局（截图 + DevTools 2026-08-19）

完整功能探查见 [explore-probe.md](./explore-probe.md)。本页只留布局骨架与借/不借。

## 四块

| 区 | 实际是什么 |
|----|------------|
| 左 | 项目/文件夹列表，可整栏关掉。顶：侧栏开关/新建文件夹/新建项目/文档阅读/导入。中：常驻对话、本机/云端项目。底：设置、账户 |
| 中 | **一张**大卡片，四周留空。标题、卡头三钮（复制类/收藏/删）、消息流、轮次折叠、空态/章节水印 |
| 右 | **节点图**，不是文字树。圆点 + 曲线。当前点实心较大，其它空心；可有未读小点 |
| 底 | 作曲条贴在**卡片外**下方：模型 + 上下文环 + 输入（Enter 换行 / Ctrl+Enter 发送）。**卡下沿外**另有三个圆钮：分支 / 子卡 / 发散 |

## 该借

1. 左栏是宇宙/项目，不是树。树/图在右边。
2. 右栏是空间节点图，点一下换卡。层级用点和线，不用缩进列表。
3. 中间只放当前探究卡，不顶边。
4. 输入条在卡外，不塞进卡里。
5. 卡片自己的工具和消息 hover 长在卡上。
6. 左栏可关，卡片变大。
7. 旧对话轮次可折叠；长按/悬停解释陌生控件。

## 不借

- 粉彩玩具风（Sakura 等皮肤）
- 登录墙当主文案
- 「本机 / 云端」当产品身份（Soit 是本机一库一宇宙）
- 把树做成第三种工作区列表
- 第三种「分支卡=带 transcript 平行分叉」——Soit 重来在卡内
- 思维宇宙作为第二套记忆

## DevTools 已拆（摘要）

- 卡头：从此卡片创建**新卡片(子)** / 收藏卡片 / 删除此卡片及其子卡片
- 卡下沿外：思维宇宙 / **分支** / **发散**（子卡不在这里）
- 轮次 hover 条：从此对话创建新/散/支 + 收藏对话 + 重新生成 + 删除
- 划词：从选中文本创建预览 | 引用选中文本 | 复制
- 标注：hover 高亮 → 点击浮层 → 浮层上三向长卡
