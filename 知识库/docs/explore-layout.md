# Explore 布局（截图 2026-08-19）

先记可借鉴处。原型未改。交互细节等 Chrome DevTools 拆完再定。

## 四块

| 区 | 实际是什么 |
|----|------------|
| 左 | 项目/文件夹列表，可整栏关掉。常驻对话、本机/云端项目。底：设置、账户 |
| 中 | **一张**大卡片，四周留空。标题、卡片工具条、消息、空态水印 |
| 右 | **节点图**，不是文字树。圆点 + 曲线。当前点实心，其它空心 |
| 底 | 作曲条贴在卡片外下方：模型 + 输入。卡片下沿另有三个圆钮 |

## 该借

1. 左栏是宇宙/项目，不是树。树/图在右边。
2. 右栏是空间节点图，点一下换卡。层级用点和线，不用缩进列表。
3. 中间只放当前探究卡，不顶边。
4. 输入条在卡外，不塞进卡里。
5. 卡片自己的工具和消息 hover 长在卡上。
6. 左栏可关，卡片变大。

## 不借

- 粉彩玩具风
- 登录墙当主文案
- 「本机 / 云端」当产品身份（Soit 是本机一库一宇宙）
- 把树做成第三种工作区列表
